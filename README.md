# Porto Verde — an open-world crime story

[![gta6-01](https://make.fun/badge/gta6-01.svg)](https://make.fun/bounty/gta6-01)
[![rank](https://make.fun/badge/gta6-01/hamkazhaa/makefun-gta6-01/rank.svg)](https://make.fun/bounty/gta6-01)
[![reward](https://make.fun/badge/gta6-01/hamkazhaa/makefun-gta6-01/reward.svg)](https://make.fun/bounty/gta6-01)

Rico Vega, an ex-wheelman, returns to the sun-bleached coastal city of
Porto Verde to settle a debt. A complete open-world crime game in the
browser: a 9×9-block city to explore on foot and by car, traffic and
pedestrians, cars to steal, a 1–5 star wanted level with police cars, foot
cops and a searchlight helicopter, three story jobs and repeatable courier
work, pistol combat, a dense HUD with a big round minimap, an in-game clock
and radio, day → deep dusk → night, a lively beach, and a save system.

Built for [make.fun's "Make GTA 6" bounty](https://make.fun/bounty/gta6-01)
with three.js and fully synthesized WebAudio — no network requests, no
commercial assets, everything original.

## Play

Serve `game/` with any static server and open `game/index.html` in a
desktop browser:

```
node serve.ts   # then open http://localhost:8080
```

- **WASD** move / drive, **mouse drag** look around, **E** steal a car,
  **click** shoot, **M** map, **Q** change radio station, **R** reload,
  **P** pause.
